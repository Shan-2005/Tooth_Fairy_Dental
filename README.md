## ✨ Features & Architecture

* **Mobile-First Conversion Architecture:**
  * **Concierge Mobile Drawer:** Full-screen frosted-glass drawer featuring live clinic hours, direct appointment booking, and 1-tap phone calls.
  * **Ergonomic Above-the-Fold Hero:** High-contrast priority booking CTA with dual 50/50 sub-actions for direct clinic phone call and WhatsApp consultation.
  * **Horizontal Treatments Filter:** Touch-scrollable category track (`Dental Implants`, `Rotary RCT`, `Laser Gum Care`, `Zirconia Crowns`, `Clear Aligners`, `Wisdom Extractions`) eliminating mobile scroll fatigue.
  * **Interactive Before & After Smile Slider:** GPU-accelerated CSS `clip-path` with touch-friendly 4:3 aspect ratio and drag handles.
  * **Dental Symptom Checker:** 2-column triage engine providing immediate clinical guidance, urgency ratings, and WhatsApp booking.
  * **Interactive Dental Cost Estimator:** Real-time treatment cost calculation with flexible 0% interest EMI ballparks and mobile live recap strip.
  * **Fixed Bottom Action Dock:** Persistent quick-action bar (`Call Now`, `WhatsApp`, `Book Slot`) with safe-area insets.

## 🚀 Getting Started

To run the clinic website locally:

```bash
# Clone the repository
git clone https://github.com/Shan-2005/Tooth_Fairy_Dental.git

# Navigate to project directory
cd Tooth_Fairy_Dental

# Run using any local HTTP server (e.g. Python)
python -m http.server 3000
```

Open your browser at `http://localhost:3000`.
